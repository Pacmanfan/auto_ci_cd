# Migrated Work Documents

`work/tasks/` contains task documents retained from the earlier task system.
The stable IDs and current status are maintained in `work/work.txt`; this
directory is not a second requirements authority.

## Classification

* `<task document>.md` -> `WORK-NNNNNN`, <status>

*(Extraction note: the source project's migrated task documents were not extracted.)*

When a task is completed, keep its report and move/update the work record under
`work/completed/`; do not create a duplicate copy under `docs/work/tasks/`.

# Requirements Traceability

This directory contains lightweight requirement-to-work-to-test-to-evidence
maps. It is an index, not a second requirements authority.

Each trace should answer:

```text
REQ -> WORK -> implementation -> TEST -> VER
```

The first process trace is `REQ-DEVOPS-001..014` in
`TEST-DEVOPS-001.md`. Domain traces may be added as work is processed; do not
invent a trace entry for a requirement that has not been verified.

# Test Intents

Per-requirement test intents (`TEST-*`) describe what verification aims to
prove, not how a test is implemented. Requirement traces live in
`docs/verification/requirements-trace/`.

Current process intent: `TEST-DEVOPS-001.md`.

Example domain intent (PROJECT-SPECIFIC; the source project's example was a
UI coordinate-mapping intent): `TEST-<DOMAIN>-NNN` — the observable outcome
the verification must prove, with its tolerance.
